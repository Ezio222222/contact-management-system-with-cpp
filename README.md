# 📒 Contact Management System (C++)

A simple Contact Management System built using C++ that allows users to manage contacts with features like adding, viewing, searching, editing, deleting, saving, and loading contacts from files. This project is designed for beginners to practice vectors, file handling, and basic C++ programming concepts.

## 🚀 Features
- Add multiple contacts (name, phone, email)
- View all saved contacts
- Search contacts by name, phone, or email
- Edit existing contacts
- Delete contacts
- Save contacts to a `.txt` file
- Load contacts from a `.txt` file
- Display available `.txt` files in the directory
- Console-based menu system

## 🛠️ Technologies Used
- C++
- STL (vector, string, fstream, sstream)
- File handling
- `<filesystem>` library
